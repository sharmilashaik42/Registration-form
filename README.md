# Registration-form
# 🚀 Classic Launch – Registration Form

A modern and responsive **registration form** built using **HTML, CSS, Bootstrap, jQuery, and Font Awesome**.  
This project focuses on clean UI design, icon support, and basic frontend validation.

---

## ✨ Features

- 🎨 Modern gradient UI design
- 📱 Fully responsive (mobile & desktop)
- 🔐 Password show/hide toggle
- 📊 Real-time password strength indicator
- ✅ Form validation (frontend only)
- ⭐ Font Awesome icons integrated

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- Bootstrap 5  
- JavaScript (jQuery)  
- Font Awesome  

---
## ▶️ How to Run the Project

1. Download or clone the repository  
2. Open `register.html` in any modern web browser  
3. Fill in the form and test the UI interactions  

_No backend or server setup required._
